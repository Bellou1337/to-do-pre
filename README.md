# Список дел

Приложение позволяет добавлять, удалять, копировать и редактировать задачи. Список сохраняется в localStorage и восстанавливается после обновления страницы.

Для редактирования нажмите на карандаш. Изменение сохраняется при выходе из поля или нажатии Enter. Escape отменяет изменение.

Для запуска откройте index.html или запустите локальный сервер из папки проекта:

```sh
python3 -m http.server 8001
```

Приложение будет доступно по адресу http://localhost:8001.
